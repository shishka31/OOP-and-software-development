1. Проблема. Описание на языке предметной области
В небольшой коллекции книг отсутствует удобный способ хранения и быстрого поиска информации о книгах. Данные хранятся разрозненно, что затрудняет добавление новых книг, просмотр всего списка, поиск по автору и удаление устаревших записей

2. Цель
Разработать простую программу с использованием объектно-ориентированного подхода, которая позволяет управлять списком книг с сохранением данных в базе данных

3. Исходные данные
Название книги (строка)
Автор книги (строка)
Год издания (целое число)
Идентификатор книги (целое число, генерируется автоматически)

4. Анализ
Для решения задачи необходимо:
Создать класс Book, описывающий одну книгу (название, автор, год, идентификатор)
Создать класс Library, который инкапсулирует работу с базой данных SQLite (создание таблицы, добавление, получение, поиск и удаление записей)
Реализовать простое текстовое меню для взаимодействия с пользователем
Обеспечить сохранение всех данных в отдельном файле базы данных library.db, чтобы информация не терялась после завершения работы программы

5. Ожидаемый результат
Рабочая программа, которая:
При запуске автоматически создаёт файл базы данных (если его ещё нет)
Позволяет через меню: добавлять новые книги, просматривать весь список книг, искать книги по автору (или части имени автора), удалять книгу по её идентификатору
Корректно сохраняет все изменения в базе данных

6. Критерии оценки ожидаемого результата
Программа запускается без ошибок
База данных создаётся и сохраняется в отдельном файле
Все основные операции работают корректно
Используется объектно-ориентированный подход
Данные не теряются после перезапуска программы
Код простой, понятный и легко расширяемый
