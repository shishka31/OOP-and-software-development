1. Добавление новой книги
актёр: пользователь
входное условие: программа запущена, база данных доступна
триггер: пользователь выбирает пункт «добавить книгу»
основные шаги:
1.  система запрашивает название книги
2.  пользователь вводит название
3.  система запрашивает автора
4.  пользователь вводит автора
5.  система запрашивает год издания
6.  пользователь вводит год
7.  система сохраняет книгу в базу данных и выводит сообщение об успешном добавлении

2. Просмотр всех книг
актёр: пользователь
входное условие: программа запущена
триггер: пользователь выбирает пункт меню «показать все книги»
основные шаги:
1.  система обращается к базе данных и получает список всех книг
2.  если список пуст — система сообщает, что библиотека пуста
3.  если книги есть — система выводит каждую книгу в формате: [ID] «Название» — Автор (Год)

3. Поиск книг по автору
актёр: пользователь
входное условие: программа запущена, в базе данных есть хотя бы одна книга
триггер: пользователь выбирает пункт «найти книги по автору»
основные шаги:
1.  система запрашивает имя автора (или его часть)
2.  пользователь вводит строку поиска
3.  система ищет книги, у которых автор содержит введённую строку
4.  если книги найдены — система выводит их список
5.  если ничего не найдено — система сообщает об этом

4. Удаление книги
актёр: пользователь
входное условие: программа запущена, в базе данных есть хотя бы одна книга
триггер: пользователь выбирает пункт «удалить книгу»
основные шаги:
1.  система запрашивает ID книги
2.  пользователь вводит ID
3.  система пытается удалить книгу с указанным ID
4.  если книга найдена и удалена — система сообщает об успешном удалении
5.  если книга с таким ID не существует — система сообщает об ошибке

5. Завершение работы с программой
актёр: пользователь
входное условие: программа запущена
триггер: пользователь выбирает пункт «выход»
основные шаги:
1.  система выводит прощальное сообщение
2.  программа корректно завершает работу
